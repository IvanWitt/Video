# Witt louncher

Minimalist Android home launcher by Ivan Witt.

Author: Ivan Witt  
Work email: svc.witt@gmail.com

Core behavior: text-only home screen, searchable app drawer, and optional automatic launch when a search leaves exactly one matching installed application.

The minimalist launcher concept is inspired by Olauncher; this module is an independent implementation for the Witt louncher project.
