# 13×20 Clock — Android Widget

Android App Widget с альтернативными аналоговыми часами и календарём майя.

## Что показывает виджет

- аналоговый циферблат на 13 часов;
- каждый час делится на 20 альтернативных минут;
- 13×20 равномерно распределены по обычным 24 часам устройства;
- текущий день Цолькина + день Хааба;
- Длинный счёт майя;
- корреляция GMT: 584283;
- расчёт даты выполняется по локальной дате и часовому поясу Android-устройства.

## Установка

GitHub Actions автоматически собирает debug APK. Откройте вкладку **Actions → Android APK**, выберите последний успешный запуск и скачайте артефакт **ThirteenClock-debug**.

После установки откройте приложение и нажмите **Добавить виджет на рабочий стол** либо добавьте его через стандартное меню виджетов Android.

## Примечание об обновлении часов

Для максимально точного минутного обновления Android может потребовать разрешение на точные будильники. Если оно недоступно, приложение использует допустимое системой неточное обновление.
